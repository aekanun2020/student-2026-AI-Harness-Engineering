## คำถามตัวอย่าง

🟢 **ไฟล์ที่ 1 — เรียก AI ครั้งแรก + ดูว่าใช้ token ไปเท่าไร:**

```bash
python labs/lab2_llm/first_llm.py "อธิบาย Agent Loop ใน 2 ประโยค"
```

**สิ่งที่ควรสังเกต:** บรรทัด `[token] prompt=… completion=… total=…` — `prompt` คือ token ของสิ่งที่ส่งไป
(system prompt + คำถาม), `completion` คือ token ของคำตอบ — ลองถามคำถามยาวขึ้น/สั้นลงแล้วดูตัวเลขเปลี่ยน

🟢 **ไฟล์ที่ 2 — ส่งคำถามเดียวกันให้ 3 โมเดล:**

```bash
python labs/lab2_llm/compare_models.py
```

**สิ่งที่ควรสังเกต:** ตารางท้ายผลลัพธ์ — โมเดลไหนตอบเร็ว/ช้า ใช้ token มาก/น้อย และคำตอบต่างกันแค่ไหน
(ไฟล์นี้เรียก 3 โมเดลในครั้งเดียว จึงมีค่าใช้จ่ายมากกว่าไฟล์อื่น) — ถ้าโมเดลใดขึ้น `ERROR` ในตาราง
มักเป็นเพราะโมเดลนั้นบน OpenRouter ไม่ว่างชั่วคราว ไม่ใช่คุณทำผิด ลองรันใหม่

## แบบฝึกหัดสำหรับผู้เรียน

| # | ระดับ | ทำอะไร | สิ่งที่ควรสังเกต |
| --- | --- | --- | --- |
| 1 | 🟢 | `python labs/lab2_llm/first_llm.py "ตอบว่า ok คำเดียว"` | `completion` ควรเล็กมาก (ไม่กี่ token) เทียบกับคำถามยาวๆ |
| 2 | 🟢 | ถามคำถามเดิม 2 ครั้ง | คำตอบไม่จำเป็นต้องเหมือนกันเป๊ะ — AI มีการสุ่มในตัว (นี่คือเหตุผลที่ Lab 4 ต้องมี hook ที่ "deterministic") |
| 3 | 🟡 | เปิด `labs/lab2_llm/compare_models.py` แก้รายชื่อใน `MODELS = [...]` (ใส่/ลบชื่อโมเดลตามที่ OpenRouter มี) แล้วรันใหม่ | ตารางเปลี่ยนตามรายชื่อ — เป็นวิธีเลือกโมเดลให้เหมาะกับงาน/งบ |
