## คำถามตัวอย่าง

🟢 **ไฟล์ที่ 1 — เรียก AI ครั้งแรก + ดู token และค่าใช้จ่าย:**

```bash
python labs/lab2_llm/first_llm.py "อธิบาย Agent Loop ใน 2 ประโยค"
```

**บรรทัดที่ต้องมองหา:**
- `[token] prompt=… completion=… total=…` — `prompt` คือ token ของสิ่งที่ส่งไป (system prompt + คำถาม),
  `completion` คือ token ของคำตอบ
- `[cost]  $0.00xxxx USD  (≈ 0.0x บาท)` — **เงินที่ถูกหักจริง**จากเครดิต OpenRouter สำหรับการเรียกครั้งนี้

🟢 **ไฟล์ที่ 2 — ส่งคำถามเดียวกันให้ 3 โมเดล:**

```bash
python labs/lab2_llm/compare_models.py
```

**บรรทัดที่ต้องมองหา:** คอลัมน์ `cost_usd` ในตารางท้ายผลลัพธ์ และบรรทัด `รวมทั้งการเปรียบเทียบ` —
โมเดลไหนแพง/ถูก และรวมแล้วครั้งนี้เสียไปเท่าไร — ถ้าโมเดลใดขึ้น `ERROR` มักเป็นเพราะโมเดลนั้นบน OpenRouter
ไม่ว่างชั่วคราว ไม่ใช่คุณทำผิด ลองรันใหม่

## แบบฝึกหัดสำหรับผู้เรียน

| # | ระดับ | ทำอะไร | บรรทัดที่ต้องมองหา / สิ่งที่ควรสังเกต |
| --- | --- | --- | --- |
| 1 | 🟢 | `python labs/lab2_llm/first_llm.py "ตอบว่า ok คำเดียว"` | `completion` ควรเล็กมาก (ไม่กี่ token) และ `[cost]` ต่ำกว่าคำถามยาวๆ ชัดเจน — **คำตอบสั้น = จ่ายน้อย** |
| 2 | 🟢 | `python labs/lab2_llm/first_llm.py "เขียนเรียงความเรื่อง AI ยาว 5 ย่อหน้า"` | `completion` พุ่ง และ `[cost]` แพงกว่าข้อ 1 หลายเท่าทั้งที่คำถามสั้น — **token ขาออก (completion) แพงกว่าขาเข้า** ดูสัดส่วนใน `[token]` เทียบกับ `[cost]` |
| 3 | 🟢 | ถามคำถามเดิม (ข้อ 1) 2 ครั้ง | คำตอบไม่จำเป็นต้องเหมือนกันเป๊ะ และ `[cost]` อาจต่างกันเล็กน้อยตามความยาวคำตอบ — AI มีการสุ่มในตัว (นี่คือเหตุผลที่ Lab 4 ต้องมี hook ที่ "deterministic") |
| 4 | 🟢 | รัน `compare_models.py` แล้วดูตาราง | หาโมเดลที่ **token ใกล้กันแต่ cost ต่างกันมากที่สุด** — ต่างกันกี่เท่า? นี่คือความต่างของ "ราคาต่อ token" ระหว่างโมเดล ไม่ใช่ความต่างของความยาวคำตอบ |
| 5 | 🟡 | เปิด `labs/lab2_llm/compare_models.py` แก้รายชื่อใน `MODELS = [...]` (ใส่/ลบชื่อโมเดลตามที่ OpenRouter มี) แล้วรันใหม่ | ตารางและยอดรวมเปลี่ยนตามรายชื่อ — เป็นวิธีเลือกโมเดลให้เหมาะกับงาน/งบก่อนใช้จริง |
| 6 | 🟡 | เปิด `labs/lab2_llm/first_llm.py` แก้ `USD_TO_THB = 36.0` เป็นอัตราแลกเปลี่ยนวันนี้ | ตัวเลขบาทในบรรทัด `[cost]` เปลี่ยน — ตัวเลข USD ไม่เปลี่ยน เพราะนั่นคือค่าจริงที่ OpenRouter หัก |

> เฉลยเชิงพฤติกรรม ไม่ใช่เฉลยคำตอบตายตัว — ประโยคคำตอบของ AI และตัวเลข token/cost จะต่างกันทุกครั้ง สิ่งที่
> ควรตรงคือ **โครงสร้างผลลัพธ์** (บรรทัด `[token]`, `[cost]`, ตารางเปรียบเทียบ) และ**ทิศทาง**ของความต่าง
> (ยาวกว่าแพงกว่า, โมเดลใหญ่แพงกว่า) ไม่ใช่ตัวเลขเป๊ะๆ
