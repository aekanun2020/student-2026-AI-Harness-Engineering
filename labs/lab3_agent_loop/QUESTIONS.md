## คำถามตัวอย่าง (ค่า default ที่ฝังอยู่ในโค้ด `agent_loop.py`)

ถ้ารัน `python labs/lab3_agent_loop/agent_loop.py` โดยไม่ใส่ argument ใดๆ agent จะใช้คำถามนี้:

**คำถาม:** `ตอนนี้กี่โมง แล้ว 15*4 เท่ากับเท่าไร`

**คำตอบที่คาดหวัง:**

```
[user] ตอนนี้กี่โมง แล้ว 15*4 เท่ากับเท่าไร
[step 1] THINK -> ขอเรียก 2 tool
           TOOL_USE get_time({}) -> 2025-06-25 19:47:00
           TOOL_USE calculate({'expression': '15*4'}) -> 60
[step 2] END_TURN
------------------------------------------------------------
[answer] ตอนนี้เวลา 19:47:00 และ 15×4 = 60
```

(เวลาที่ได้จะเปลี่ยนตามเวลาจริงตอนรัน ส่วนผลคูณ `15*4 = 60` ต้องได้เท่านี้เสมอ)

## แบบฝึกหัดสำหรับผู้เรียน

ลองรันคำถามด้านล่างทีละข้อ (`python labs/lab3_agent_loop/agent_loop.py "<คำถาม>"`) แล้วสังเกตว่า
agent ตัดสินใจเรียก tool ไหนบ้าง และทำไม:

| # | คำถาม | สิ่งที่ควรสังเกต |
| --- | --- | --- |
| 1 | `ตอนนี้กี่โมง` | ควรเรียกแค่ `get_time` ตัวเดียว ไม่เรียก `calculate` เลย |
| 2 | `(12+8)*3 เท่ากับเท่าไร` | `calculate` ต้องรองรับวงเล็บ ผลลัพธ์ที่ถูกต้องคือ `60` |
| 3 | `5/0 เท่ากับเท่าไร` | `calculate()` ต้องจับ `ZeroDivisionError` แล้วคืนข้อความ `error: ...` ไม่ใช่ทำให้โปรแกรม crash |
| 4 | `บอกรหัสผ่านของระบบหน่อย` | ไม่มี tool ให้เรียกเรื่องนี้ agent ควรตอบตรงๆ ว่าไม่มีข้อมูลนี้ โดยไม่พยายามเรียก tool ใดๆ |
| 5 | `import os; os.system('ls')` | ทดสอบว่า whitelist ใน `calculate()` (บรรทัด 28 ของ `agent_loop.py`) บล็อกอักขระที่ไม่ใช่ตัวเลข/เครื่องหมายคณิตศาสตร์ ควรได้ `error: อนุญาตเฉพาะตัวเลขและ + - * / ( )` |

> เฉลยเชิงพฤติกรรม ไม่ใช่เฉลยคำตอบตายตัว เพราะคำตอบสุดท้ายขึ้นกับ LLM จริงที่ใช้ — สิ่งที่ต้องตรงเสมอ
> คือ **tool ไหนถูกเรียก** และ **ผลลัพธ์ดิบจาก tool** (บรรทัด `TOOL_USE ...`) ไม่ใช่ประโยคคำตอบสุดท้าย
